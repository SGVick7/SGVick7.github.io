# Objetivo

Desenvolver um portfólio profissional para uma social media especializada em posicionamento estratégico de marcas, apresentando serviços, processo de trabalho e cases com uma identidade visual clara, elegante e alinhada à proposta de "clareza antes de estética".

## Descrição

O CIELY é um site de portfólio criado para apresentar o trabalho de uma profissional de redes sociais focada em ajudar marcas a ocuparem um lugar próprio no mercado. O site organiza o conteúdo em páginas separadas (início, serviços, como funciona, cases e contato), com textos diretos e uma narrativa que conduz o visitante até o convite para uma conversa.

Durante o desenvolvimento, foram aplicados conceitos de estruturação semântica com HTML, estilização com CSS e recursos interativos com JavaScript, como a troca de idioma entre português, inglês e espanhol e a alternância entre tema claro e escuro. O projeto também permitiu explorar design de interfaces (UI), experiência do usuário (UX) e a construção de uma identidade visual para um serviço de comunicação.

## Funcionalidades

* Site multipágina: Início, Serviços, Como funciona, Cases e Contato.
* Seletor de idiomas (português, inglês e espanhol).
* Alternância entre modo claro e modo escuro.
* Página de serviços com o escopo do trabalho: posicionamento de marca, estratégia de conteúdo, gestão de redes sociais e consultoria pontual.
* Página de cases estruturada para apresentar projetos e resultados.
* Seção de apresentação com a proposta de valor e ilustração do mapa de posicionamento.
* Chamadas para ação com envio de e-mail e botão direto para o WhatsApp.
* Links para Instagram, LinkedIn e Behance.
* Layout responsivo para diferentes dispositivos.
* Publicação da aplicação utilizando GitHub Pages.
