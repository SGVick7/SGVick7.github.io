# Objetivo

Desenvolver um site de catálogo para uma loja de acessórios, apresentando as peças de forma elegante e organizada, com uma interface limpa, responsiva e focada na experiência do usuário, além de facilitar o contato direto entre cliente e vendedora.

## Descrição

A VYCK Acessórios é um projeto de desenvolvimento web criado para apresentar uma coleção de peças exclusivas, como colares, brincos e anéis. O site foi pensado para transmitir a identidade da marca, com textos de apresentação, destaque visual para os produtos e uma navegação simples entre as seções.

Durante o desenvolvimento, foram aplicados conceitos de estruturação semântica com HTML, estilização responsiva com CSS e recursos interativos com JavaScript, como o sistema de favoritos, que permite ao visitante guardar as peças de que mais gostou e consultá-las em uma página própria. O projeto também permitiu explorar aspectos de design de interfaces (UI) e experiência do usuário (UX) aplicados a um pequeno comércio online.

## Funcionalidades

* Página inicial com apresentação da marca e chamada para a coleção.
* Seção "Peças Disponíveis" com a vitrine dos acessórios.
* Seção "Nossa história" apresentando a proposta e a curadoria das peças.
* Sistema de favoritos: botão de coração nas peças, contador no topo do site e página dedicada com as peças guardadas.
* Seção de contato com links diretos para WhatsApp e Instagram.
* Navegação por âncoras entre as seções (Sobre, Contato e Coleção).
* Layout responsivo para diferentes dispositivos.
* Publicação da aplicação utilizando GitHub Pages.
