Objetivo

Desenvolver uma plataforma web inspirada em serviços de streaming para centralizar conteúdos relacionados ao grupo Stray Kids, oferecendo uma interface moderna, intuitiva e responsiva, com foco na experiência do usuário e na aplicação de boas práticas de desenvolvimento front-end.

Descrição

O SKZFLIX é um projeto de desenvolvimento web que reproduz a experiência visual de plataformas de streaming, adaptando esse conceito para a organização de conteúdos do grupo Stray Kids. A aplicação foi desenvolvida com o objetivo de proporcionar uma navegação simples e agradável, reunindo vídeos, músicas, álbuns, perfis dos integrantes e outros conteúdos em um único ambiente.

Durante o desenvolvimento, foram aplicados conceitos de estruturação semântica com HTML5, estilização responsiva utilizando CSS3 e implementação de recursos interativos com JavaScript. O projeto também permitiu explorar aspectos relacionados ao design de interfaces (UI), experiência do usuário (UX) e organização de aplicações web estáticas.

Funcionalidades

  • Interface inspirada em plataformas de streaming.
  • Layout responsivo para diferentes dispositivos.
  • Navegação intuitiva entre as seções do site.
  • Organização de conteúdos em categorias.
  • Exibição de informações sobre músicas, álbuns e integrantes.
  • Elementos visuais e animações para melhorar a experiência do usuário.
  • Publicação da aplicação utilizando GitHub Pages.
